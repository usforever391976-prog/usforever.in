# US Forever Films & Entertainment — Website

A free, responsive, cinematic production-house website for GitHub Pages.

## Files
- `index.html`
- `style.css`
- `script.js`
- `assets/logo.jpg`

## GitHub Pages
1. Upload all files to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Save.
6. GitHub will provide your free `github.io` website address.

## Custom domain
When you own `usforever.in`, open **Settings → Pages → Custom domain**, enter `usforever.in`, and follow GitHub's DNS instructions at your domain registrar.

## Updating the site
Replace the placeholder project/gallery areas in `index.html` with your posters and project images. Keep the `assets` folder for images.
